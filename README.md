# github_Demo
This is a demo repository to get a better understanding of the fundamentals of Git and Github learning essential git commands and their uses.
<br>
The first step is to make a Github account with a username and email id with a strong password.
<br>
The second step is to install Git Bash from git-scm.com , Git (latest version) using CMD, and most essentially a smart code editor like VS Code into your system.
